# SIAMAT-TVRI-KALSEL
Sistem Informasi Manajemen Terintegrasi TVRI Kalimantan Selatan

Ini adalah project Laravel 12.68 dengan database MySQL yang digunakan untuk aplikasi SIAMAT TVRI Kalimantan Selatan.

## Persyaratan Sistem
- PHP >= 8.3
- MySQL >= 8.0
- Composer

## Cara Menjalankan Project
1. Clone repositori ini.
2. Jalankan `composer install`.
3. Salin `.env.example` ke `.env` dan konfigurasikan database Anda.
4. Jalankan `php artisan key:generate`.
5. Jalankan `php artisan migrate`.
6. Jalankan `php artisan serve`.
